Act as an award-winning Product Designer, Staff Frontend Engineer, Creative Director, and UI/UX expert.

Your task is to design and build a world-class personal portfolio website for me. This is not just another developer portfolio—it is my personal brand and the central hub of my professional identity.

The website should immediately communicate professionalism, technical excellence, attention to detail, and modern engineering taste. I want visitors, especially recruiters and hiring managers, to feel like they're interacting with a polished digital product rather than a portfolio template.

My target role is AI Engineer / Machine Learning Engineer.

The overall visual style should be inspired by Apple, Linear, Vercel, Raycast, Stripe, and premium editorial portfolio websites. The design must feel elegant, minimal, sophisticated, spacious, and timeless. Avoid trendy effects that will look outdated in a year.

Use a dark-first design with a monochrome palette. My favorite color is yellow, but it should be used sparingly—only for important buttons, highlights, links, hover states, active navigation, and subtle accents. The interface should remain approximately 95% monochrome. The yellow should become part of my visual identity without overwhelming the design.

Typography is extremely important. Use large editorial headings, beautiful spacing, consistent alignment, and excellent visual hierarchy. Every section should breathe with generous whitespace. Every animation should feel intentional, smooth, and premium. Avoid flashy effects, excessive glassmorphism, giant gradients, bouncing elements, or unnecessary motion.

The website should include the following sections in this order:

• Hero
• About
• Selected Work (Projects)
• Tech Stack
• Journey (Experience & Education Timeline)
• Capabilities
• GitHub
• Ask Nithish AI
• Contact
• Footer

Hero:
Create a powerful first impression. Use a professional corporate headshot(Corporate Headshot Picture.jpg) on the right and a bold headline on the left. Do not introduce me as a student or use generic phrases like "passionate developer." Instead, communicate what I build and the impact I aim to create. Include two CTA buttons: "View My Work" and "Download Resume."

About:
This should not read like a resume. Explain how I think as an engineer, the kinds of problems I enjoy solving, and my philosophy toward building software. Include elegant cards for Education, Currently Exploring, and Engineering Principles.

Selected Work:
This is the most important section after the Hero. Use premium project cards with large thumbnails, technology tags, GitHub links, Live Demo buttons, and space for detailed case studies. Use placeholder projects for now because I will replace them later.

Tech Stack:
Group technologies by category such as Languages, AI/ML, Frameworks, Databases, Cloud, and Tools. Display them as elegant badges instead of progress bars or charts.

Journey:
Create a beautiful vertical timeline showing my education, internship, major projects, and milestones.

Capabilities:
Display my strengths using clean pills or cards instead of percentage bars.

GitHub:
Design a section that can later integrate with the GitHub API to display repositories, contribution graphs, and recent activity.

Ask Nithish AI:
This should become the signature feature of the portfolio. Design it as a premium AI product, not a chatbot widget. Build a beautiful chat interface where visitors can ask questions about me, my projects, skills, or experience. For now, use local mock data and placeholder responses. Architect the component so it can later be connected to OpenAI, Gemini, Claude, or a Retrieval-Augmented Generation (RAG) pipeline without major refactoring. This feature should feel like an interactive AI assistant that makes the portfolio memorable.

Contact:
Keep it minimal and elegant with email, LinkedIn, GitHub, and Resume.

Technical Requirements:
Use Next.js 15, React 19, TypeScript, Tailwind CSS, Framer Motion, shadcn/ui, Lucide Icons, next/image, and next/font. Write clean, modular, production-ready code using reusable components. Organize content into reusable data files so adding new projects later requires minimal code changes.

Performance and Accessibility:
Optimize images, lazy load where appropriate, follow semantic HTML, provide keyboard accessibility, proper focus states, excellent Lighthouse scores, and responsive layouts across desktop, tablet, and mobile.

Avoid:
Progress bars, fake testimonials, fake client logos, fake statistics, circular charts, template-style sections, bright gradients, excessive glassmorphism, unnecessary animations, or generic developer portfolio clichés.

Finally, before generating the code, think like an Awwwards judge, a recruiter hiring an AI Engineer, and a senior product designer. Challenge every design decision. If something feels ordinary, redesign it until it feels premium, memorable, and handcrafted. The final result should look like the personal website of an AI engineer who deeply cares about both engineering excellence and exceptional design.
